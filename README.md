# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/1GdIzW1MmiCRh88zAbbYip5A3Ndf38Ww6

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set your `GROQ_API_KEY` in [.env.local](.env.local) (obtain one at https://console.groq.com/keys)
3. Run the app:
   `npm run dev`
